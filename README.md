RANDOLPH PREMIUM REDESIGN

1. Extract this ZIP.
2. Open the randolph-premium folder in Visual Studio Code.
3. Install the Live Server extension if you don't already have it.
4. Right-click index.html and choose "Open with Live Server".

FILES:
- index.html = page structure/content
- style.css = all design and responsive styling
- script.js = navigation, animation, and demo service search

NOTE:
This is an independent portfolio redesign concept and is NOT the official Town of Randolph website.
The project uses externally hosted imagery for demonstration. For a production site, replace those URLs with licensed/local image assets.
